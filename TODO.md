## The only thing that matters

- [ ] **Get the validation signal.** The go/no-go metric is not signups, it is
      the free-text answer to "who would you play with". Under 20% naming a crew
      is a kill at any volume. The criteria were written before any data existed
      so they cannot be rationalised afterwards.
- [ ] **Zero plays as of 2026-09-15.** The page is live and deploy-verified;
      nobody has played. Distribution is the open problem, not the product.
- [ ] **Tag every posted link with `?src=`** and report personal-network signups
      separately from cold. Friends playing is not the signal.

## Blocked / known

- [ ] **The form ships in preview mode and stores nothing**, deliberately, since
      a form that silently swallows real addresses is worse than one that admits
      it is unwired. It has to be wired before the test can run.
- [ ] **OSM tile licensing**, shared with `P-roadside`. Recommended fix is
      Protomaps `.pmtiles` on object storage, which unblocks both at once and is
      already the approach used in `P-driveandhear.com`.
- [ ] **Cairn is not trademark cleared.** Common noun, existing users in energy
      and academic publishing. Run a search before buying a domain.

## Standing rules, not tasks

- The puzzle is explicitly not the differentiator. Any incumbent could ship a
  better geo round tomorrow; the crew layer is the product.
- Streak advances on 2 players, not all of them. Crew score counts best 3, not
  the average. Recognition is categorical, not ranked. Archive over hints,
  always. All four are load-bearing design rules, not preferences.
- Honest ceiling for a first web game is $500 to $3,000 a month.
